# Security Policy

## Scope

This repository contains a Codex-compatible skill, prompt templates, documentation, and local helper scripts. It does not provide a hosted service and does not call an image-generation API by itself.

## Reporting Security Issues

If you find a security issue, please do not publish sensitive details in a public issue.

Use GitHub's private vulnerability reporting when available, or contact the maintainer through their GitHub profile with:

- affected file or workflow
- short description of the risk
- reproduction steps if safe to share
- suggested mitigation if known

## Privacy Expectations

Do not submit:

- API keys, tokens, credentials, or secrets
- private prompts
- client names or private project facts
- private maps, plans, emails, documents, or images
- absolute local filesystem paths

When reporting prompt-template issues, summarize the reusable pattern instead of pasting confidential source material.

## Supported Versions

The latest release and the `main` branch are the only supported versions.
