# Template Index

Use this index before loading a detailed template card.

## Board and Exhibition Templates

- `river-ecology-competition-board`: satellite or river map to dense vertical river ecology competition board.
- `urban-waterfront-intervention-board`: city satellite map to left-heavy waterfront renewal board with intervention paths.
- `style-transfer-design-board`: one board as style/layout reference and one map/satellite/plan as factual content.
- `biodiversity-ecology-board`: ecological or waterfront scene to biodiversity and remediation presentation board.
- `city-culture-context-board`: city/country research to architectural culture and urban context collage board.
- `rendering-to-sasaki-board`: existing site rendering to Sasaki-like analytical competition board.

## Map, Location, and Site Analysis Templates

- `accurate-location-map-analysis`: true map plus style reference to accurate location analysis with optional web verification.
- `satellite-to-site-analysis`: satellite image to dark competition-style urban/landscape analysis map.
- `creative-location-analysis`: map to creative continuous city-surface / street-valley / lifted-axis location analysis.
- `map-to-renewal-plan`: map or satellite to soft pastel 2.5D renewal design plan.

## Image-To-Diagram Templates

- `architecture-exploded-axonometric-diagram`: building image, drawing, model screenshot, plan/section bundle, or architectural reference to clean exploded axonometric analysis diagram with built-in white-gray/orange/red competition style.
- `rendering-to-analysis-diagram`: rendering to strategy diagram while preserving original perspective and geometry.
- `photo-to-section-analysis`: site photo to horizontal ecological corridor section-analysis board.
- `photo-to-ecology-vision`: real site photo/map to panoramic ecological vision diagram with analysis overlays.
- `site-photo-to-collage-render`: real site photos plus public context to white-background stage collage rendering.

## Perspective Scene Templates

- `plan-point-to-perspective-render`: marked plan point and arrow to human-eye-level architectural/landscape collage perspective.

## Excluded From v1

Do not include game interior scenes or architecture promotional videos in this skill. Route them to a future separate skill.
