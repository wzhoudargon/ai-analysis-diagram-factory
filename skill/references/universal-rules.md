# Universal Rules

## Input Roles

- Evidence images are the only source for geometry, facts, place, site content, and real spatial relationships.
- Style images are only for composition, color, mood, rendering language, graphic grammar, and annotation style.
- Output examples are only for output type and quality target.

## Geometry Lock

Activate strict geometry lock for maps, satellite images, CAD, plans, sketches, site photos, and existing renderings when accuracy matters.

Preserve analysis-critical:

- river, shoreline, canal, lake, pond, wetland, and water morphology
- roads, paths, bridges, entrances, transit corridors, and circulation hierarchy
- buildings, blocks, boundaries, parcels, open spaces, and topography
- image-plane position, direction, relative scale, and outline character

Style may change. Factual geometry must not drift unless the user explicitly asks for redesign.

## Text

- Prefer short labels and deterministic post-edit overlays for exact Chinese or dense annotations.
- Ask the image model for minimal diagrammatic labels only.
- Forbid fake paragraphs, UI text, watermarks, logos, reference captions, and random glyphs.

## Web Verification

Use web research only for public, source-checkable names and context: administrative location, roads, water bodies, parks, transit, landmarks. Do not invent private project scope or design goals from web results.

## Failure Threshold

Treat these as not ready:

- key geography, plan, shoreline, road, or building structure changed
- style reference content leaked into the result
- output type changed, such as board becoming illustration
- critical labels are unreadable or wrong language
- analysis marks float without relation to site geometry
